# Clawdbot AI Agent System — 심층 분석 문서

Clawdbot 오픈소스 프로젝트를 **AI 에이전트(AI 비서) 시스템** 관점에서 학습 및 문서화 목적으로 분석한 7부작 문서입니다.

## 대상 독자

- AI 에이전트(AI 비서) 시스템이 어떻게 설계되는지 알고 싶은 분
- Clawdbot이 내부적으로 어떻게 동작하는지 궁금한 분
- Clawdbot 프로젝트에 기여하거나 기능을 확장하고 싶은 분

## 용어 해설

이 문서에서 자주 등장하는 기술 용어를 쉽게 풀어 설명합니다.

| 용어 | 쉬운 설명 |
|------|-----------|
| **게이트웨이 (Gateway)** | 모든 메시지가 들어오고 나가는 **중앙 관리 서버**. 건물의 정문과 같다. |
| **에이전트 (Agent)** | 사용자의 요청을 이해하고 작업을 수행하는 **AI 비서**. |
| **세션 (Session)** | 하나의 **대화 묶음**. 같은 채팅방에서 이어지는 대화를 말한다. |
| **워크스페이스 (Workspace)** | 에이전트가 사용하는 **작업 공간**. 설정 파일과 기억이 저장된 폴더. |
| **런타임 (Runtime)** | 프로그램이 실제로 **실행되는 환경**. 에이전트가 동작하는 무대. |
| **도구 (Tool)** | 에이전트가 일을 하기 위해 사용하는 **기능**. 파일 읽기, 명령 실행 등. |
| **스킬 (Skill)** | 에이전트에게 부여할 수 있는 **능력 꾸러미**. 여러 도구를 묶은 것. |
| **컨텍스트 (Context)** | 에이전트가 대화할 때 참고하는 **전후 맥락 정보** 전체. |
| **컨텍스트 윈도우 (Context Window)** | AI가 한 번에 읽을 수 있는 **정보량의 한계**. |
| **컴팩션 (Compaction)** | 대화가 길어졌을 때 이전 내용을 **요약해서 줄이는 과정**. |
| **스트리밍 (Streaming)** | 응답을 한꺼번에가 아니라 **실시간으로 조금씩 전달**하는 방식. |
| **샌드박스 (Sandbox)** | 안전을 위해 격리된 **보호 환경**. 실험실 안의 안전 구역과 같다. |
| **훅 (Hook)** | 특정 시점에 **자동으로 실행되는 추가 기능**. 알람처럼 조건이 되면 작동한다. |
| **플러그인 (Plugin)** | 기본 기능에 추가로 끼워 넣을 수 있는 **확장 기능 모듈**. |
| **레인 (Lane)** | 작업의 **실행 순서를 관리하는 대기줄**. 차선과 비슷한 개념. |
| **바인딩 (Binding)** | 어떤 메시지를 어떤 에이전트로 보낼지 정하는 **연결 규칙**. |
| **페어링 (Pairing)** | 새로운 기기나 사용자가 시스템에 접속할 때 거치는 **인증 연결 절차**. |
| **트레이드오프 (Trade-off)** | 하나를 얻으면 다른 것을 포기해야 하는 **장단점 교환 관계**. |
| **오버라이드 (Override)** | 기본 설정을 다른 값으로 **덮어쓰기**. |
| **폴백 (Fallback)** | 실패했을 때 사용하는 **대체 처리 방법**. |
| **정규화 (Normalize)** | 다양한 형태의 입력을 **하나의 통일된 형태로 변환**하는 것. |
| **직렬화 (Serialize)** | 작업을 동시에 하지 않고 **하나씩 순서대로 처리**하는 것. |

## 각 Part 구성

모든 Part는 다음 구조를 따릅니다:

1. **한눈에 보기** — 3~5개 핵심 포인트
2. **시각화** — 구조/흐름을 그림으로 표현
3. **상세 분석** — 설계 의도와 동작 방식
4. **핵심 흐름 설명** — 프로그램의 동작 순서를 자연어로 표현
5. **학습자가 얻어야 할 포인트** — 핵심 교훈
6. **학습 관점에서 중요한 파일** — 소스 코드 참조
7. **다음 Part 예고** — 연결 흐름 (Part 7 제외)
